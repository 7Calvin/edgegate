🔐 Autenticação

Toda chamada autenticada usa Authorization: Bearer <token>. O token pode ser um JWT (obtido no login) ou uma API key de um usuário de serviço (user_type = SERVICE).

Trusted Host: o IP de origem é validado em toda requisição autenticada — um IP fora da allowlist do usuário recebe 403, mesmo com token válido.

As pílulas em cada endpoint indicam o nível: admin exige privilégio de administrador, auth qualquer usuário autenticado, público sem token.
